Proposition: Countries that are allies and developed will have a higher average CO2 emissions Per Capita than developed and non allied countires.

FOR the Proposition

Design Decisions and Rationale:

  • Different lines for each group. I decided to use this design element as one layer of distingsion between the two groups because they are almost exactly the same with the only difference being if they are all or non ally.(2)
  • Using differet markers. Another layer for distinction so that it is easier to identify which line belongs to which group making a great choice if people are color blind.(2)
  • Using a line graph. I thought it would be a great way to show over time which group has remained dominant when it comes to average CO2 emssions per capita.(2)

AGAINST the Proposition

Design Decisions and Rationale:

  • Different colors. A way for viewers to know which bar belongs to which group.(2)
  • Bar graph. A way for viewers to instantly see the visual difference between the two groups.(1)
  • Cherry picking time periods. So I can create a visualizion that has data that supports the opposite stance of my proposition.(-2)

Final Reflection

After forming my proposition I thought the best way to show the difference between developed/allay and developed/non ally would be by trying to create a graph that introduced a time element. As such I thought the best way to do that was by creating a line plot that shows not only the average CO2 emissions per capita but its relationship with the other group over time. To make sure that it was easy to distinguish between the two groups I created a different type of line and marker for each group. For this graph everything felt straight forward, nothing too difficult. The only thing that was challenging was finding out how to create the different lines and markers

For the deceptive graph it was the other way around. It was challenging for me to find a way to manipulate the data to show that there was no significant difference without violating major ethical concerns. I finally settled on choosing data over certain time periods to prove my opposite proposition. The only thing that was straightforward was to create a bar graph to show the difference between the two groups.

Something that surprised me was how difficult it was to find deceptive ways that were not major ethical compromises. I would define ethical analysis and visualization as the act of using the given data to create visualizations that show a visual and numeric change if there is any. I think there are certain boundaries for persuasive choices and misleading ones. For example it is ok to transform the data but not okay to change it. As well as make any changes that show both a visual and a numerically significant difference.
